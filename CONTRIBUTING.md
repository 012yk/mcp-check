# Contributing to mcp-check

First off, thank you for considering contributing to `mcp-check`! It's people like you that make the open-source community such an amazing place.

## 🐛 How to Report a Bug or Security Issue

If you find a bug or a new security vulnerability that `mcp-check` is missing, please open an Issue. To help me fix it quickly, please include:

1. **The specific error or risk** you encountered.
2. **A snippet of your MCP config** (e.g., `.mcp.json`). 
   * ⚠️ **IMPORTANT:** Please **REDACT** all real API keys, tokens, or sensitive data before pasting your config. Use dummy strings like `ghp_12345example`.
3. The version of Python you are using.

## 💡 How to Suggest a New Feature

If you have an idea for a new rule or a feature, open an Issue with the `enhancement` tag. Describe the feature and why it would be useful for securing MCP servers.

## 💻 How to Submit a Pull Request

1. Fork this repository.
2. Create a new branch: `git checkout -b feature-your-feature-name`.
3. Make your changes (keep it lightweight and zero-dependency!).
4. Commit your changes: `git commit -m 'Add some feature'`.
5. Push to the branch: `git push origin feature-your-feature-name`.
6. Submit a Pull Request.
